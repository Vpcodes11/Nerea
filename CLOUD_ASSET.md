## Exact final generation prompt

Use case: photorealistic-natural. Asset type: transparent cloud sprite for layers in a cinematic Three.js ocean website. Create ONE isolated wide billowing cumulus cloud bank, approximately 2.5:1 proportions, fully surrounded by generous transparent margins. Dense plush three-dimensional cotton-like rolling lobes along the top, softer drifting vapor at the base, pale pearl white with very subtle warm blush highlights and cool lavender shadows. Soft upper-left light, realistic volumetric scattering, refined high-end CGI realism. Cloud only, on an actual transparent background with delicate semi-transparent vapor edges. No sky, horizon, ground, water, scenery, objects, text, checkerboard, hard border, flat smoke strip, or cut-off edges. A clear organic cloud silhouette with natural irregularity and depth; suitable for tinting and overlapping into mist banks.
